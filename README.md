К нам обратился заказчик - музыкальная платформа, которая хочет внедрить рекомендательную систему треков и улучшить пользовательский опыт в приложении. 

Платформа располагает историей прослушиваний пользователей: какие треки слушали, лайкали, дослушивали до конца или пропускали. На основе этой истории нужно научиться предсказывать, какой трек пользователь предпочтёт. Это позволит формировать персональные рекомендации и повышать вовлечённость пользователей.

Для реализации этой задачи необходимо решить DL-задачу по ранжированию треков на основе предпочтений пользователя: для пары соседних по времени взаимодействий с разными исходами модель должна предсказать, какой трек пользователь оценит выше. На вход подаются признаки пользователя, трека и их различные взаимодействия, а на основе них полносвязная нейронная сеть и её модификации предсказывают вероятность позитивного исхода взаимодействия.


Для реализации второй задачи проекта необходимо решить задачу глубинного обучения, которая представляет собой многоклассовую классификацию треков. На вход будут подаваться аудиодорожки, из которых формируются mel-спектограммы. Далее с помощью архитектур нейронных сетей получим распредление треков по жанрам. 

Платформа делит все треки на альбомы, похожих певцов и тд. Но компания поняла, что для создания качественной рекомендательной системы необходимо понять, к какому жанру музыки относится трек. Из этого формируется бизнес-задача для нашего проекта.
2 бизнес-задача: Для пользователей платформы реализовать функционал автоматического определения жанра трека по звуку, чтобы улучшить персональную рекомендательную систему и повысить кол-во пользователей на 30%.
